HOW TO USE THIS PORTFOLIO
=========================
Files
  index.html  - the page content (text, sections)
  style.css   - colours, fonts, animations (top of file: change colours)
  script.js   - YOUR VIDEO LINKS are at the top of this file
  assets/     - pictures and the home-screen video

SEE CHANGES ON YOUR COMPUTER
  1. Open the folder in VS Code (free).
  2. Install the "Live Server" extension, right-click index.html > Open with Live Server.
  3. Every time you save a file, the page updates by itself.
  (No VS Code? Just double-click index.html. Refresh the browser after each edit.)

SEE CHANGES ONLINE, NO INSTALL
  Go to stackblitz.com or codesandbox.io, make a new "HTML/CSS/JS" project,
  and paste each file in. The preview updates as you type.

PUT IT ONLINE (free link to share)
  Option A - Netlify Drop: go to app.netlify.com/drop and drag the whole folder in.
  Option B - GitHub Pages: upload the files to a GitHub repo > Settings > Pages.

ADD YOUR REAL VIDEOS
  1. Upload your video to YouTube (Unlisted is fine) or Google Drive (share: "Anyone with the link").
  2. Open script.js, find VIDEO_EDITING, paste the link into url: "" and change title / tag.
  3. To use your own picture on the card, put a .jpg in assets/ and set thumb: "assets/yourpic.jpg".
